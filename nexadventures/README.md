# NeXAdventures Founder Command Center

Interactive static site for planning and building NeXAdventures as a connected family media, learning, technology, portfolio, and playable-world company.

## Included in this first working version

- Immersive Expedition Desk based on the approved adventure-map dashboard direction
- Clickable Company Map, Roadmap, Idea Vault, Curriculum Atlas, Passport, World Studio, Game & App, and Docs workspaces
- Searchable and filterable Idea Vault
- Responsive desktop, tablet, and mobile layouts
- Quick Capture stored in the current browser with `localStorage`
- High-level project data loaded from the NeXAdventures planning materials
- Static GitHub Pages-ready structure with no build step

## Open locally

Open `index.html` in a browser, or serve this folder with:

```bash
python -m http.server 8000
```

## Publishing note

GitHub Pages sites are generally public unless an eligible enterprise account enables private Pages access control. This first version intentionally uses high-level, public-safe summaries rather than publishing the full confidential source documents.

## Upgrade path

The next technical phase can move records from inline data and browser storage into an authenticated database while preserving this information architecture and visual system.
